# Public Maps

Public [Randow Maps](https://randowmaps.com/) — each folder is one map (`base.yaml`, optional scenario YAML files, and a `<map-id>.log.json` audit sidecar).

Served online at **https://maps.randowmaps.com**.

## Maps

| Map | Description |
|---|---|
| [product-capability](product-capability/base.yaml) | Team builds capability, capability builds product, customer gains benefit — with feedback loops. Usable as a template for many business models. |

## Adding a map

Create `<map-id>/base.yaml` following the Randow Maps schema, commit, and push. The deployed app reads this repo as a git source.
